# 🎃 Noche de Terror — Invitación

Invitación web para una maratón de películas de terror del 30 al 31 de octubre.

## Personalizar
- Textos: edita `index.html`.
- Cuenta regresiva: en `script.js`, bloque `CONFIG`, cambia `inicio`.

## Subir a GitHub Pages
1. Sube `index.html`, `style.css`, `script.js` y `README.md` al repositorio.
2. **Settings → Pages → Branch: main / (root) → Save**.
